# 🧩 Zain UI Components Library

A production-grade React component library and design system built with Vite and Tailwind CSS.

## Features

- 100+ production-ready React components
- Full dark/light mode support
- Token-based design system
- WCAG 2.1 AA accessibility compliance
- Responsive mobile-first design
- Framer Motion animations
- Polymorphic component API
- Live interactive showcase

## Tech Stack

- **React 18** — UI library
- **Vite 5** — Build tooling
- **Tailwind CSS 3** — Utility-first styling
- **Framer Motion** — Advanced animations
- **React Router DOM** — Client-side routing
- **Headless UI** — Accessible primitives

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
